Casilla saliente de la plataforma para enviar los recibos a los funcionarios. La contraseña se guarda cifrada; al editar, dejala vacía para no cambiarla. Con Gmail necesitás verificación en dos pasos y una "contraseña de aplicación" (la contraseña normal de la cuenta no sirve para SMTP).

SMS / WhatsApp (Twilio)

Cuenta de Twilio de la plataforma para mandar el código de login por SMS o WhatsApp, cuando el usuario elige ese canal. El código lo genera el sistema; Twilio solo lo transporta. El Auth Token se guarda cifrado; al editar, dejalo vacío para no cambiarlo. WhatsApp necesita una plantilla aprobada (Content SID) para mensajes de OTP; sin ella solo funciona en el entorno de pruebas (sandbox) de Twilio.

Etiquetas / Traducciones

Editá los textos de la interfaz por idioma. Tu cambio pisa el texto original (que queda como respaldo); el botón ↺ lo vuelve al original. Sirve para corregir el texto sin tocar el código, o para completar el guaraní desde acá. Importante: respetá las variables entre llaves como {email} o {canal}; si las borrás, el cambio se rechaza.
